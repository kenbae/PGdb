# Historical Data Dashboard 사용 가이드 📊

## 🎯 기능

### **1. 전체 개요**
- 총 심볼 수
- 총 데이터 건수
- 데이터 기간 (최초~최신)
- 타임프레임 종류
- 타임프레임별 분포

### **2. 드릴다운 분석**
```
전체 개요
  ↓
심볼별 조회
  ↓
년도별 조회
  ↓
월별 조회
  ↓
일별 조회
```

### **3. 실시간 업데이트**
- 10초마다 자동 갱신
- 숫자 변경 시 애니메이션 효과
- 최근 업데이트 시간 표시

### **4. DB 연결 누수 방지**
- 모든 함수에 `finally` 블록
- `with conn.cursor()` 사용
- 예외 발생 시에도 안전하게 연결 닫기

## 🎨 주요 기능 상세

### **1. 타임프레임 필터링**

메인 화면에서 타임프레임 카드 클릭:
```
클릭: "30m" 카드
  ↓
심볼별 조회 (30m만)
  ↓
BTCUSDT 선택
  ↓
년도별 조회 (BTCUSDT + 30m)
  ↓
...
```

### **2. 심볼 드릴다운**

```
심볼 목록에서 "년도별 →" 클릭
  ↓
해당 심볼의 년도별 데이터
  ↓
년도 선택 (예: 2023)
  ↓
2023년 월별 데이터
  ↓
월 선택 (예: 1월)
  ↓
1월 일별 데이터
```

### **3. Breadcrumb 네비게이션**

```
🏠 전체 개요 / 심볼 / 년도 (BTCUSDT) / 2023년

클릭: "심볼"
  ↓
심볼 목록으로 이동 (상태 유지)

클릭: "🏠 전체 개요"
  ↓
메인 화면으로 복귀
```

### **4. 실시간 업데이트**

```javascript
// 10초마다 자동 갱신
setInterval(() => {
    if (currentView === 'overview') {
        loadOverview();  // 개요 갱신
    } else {
        refreshCurrentView();  // 현재 뷰 갱신
    }
}, 10000);
```

**효과:**
- 숫자 변경 시 애니메이션
- "업데이트 중" 시각적 표시
- 마지막 업데이트 시간 표시

## 🔧 API 엔드포인트

### **GET /api/overview**
전체 개요 통계
```json
{
  "total_symbols": 150,
  "total_candles": 5200000,
  "earliest_date": "2020-01-01T00:00:00",
  "latest_date": "2026-01-18T12:00:00",
  "timeframes": [
    {"tf": "1m", "count": 500000, "symbols": 50},
    {"tf": "30m", "count": 150000, "symbols": 100}
  ]
}
```

### **GET /api/symbols?tf=30m**
심볼별 통계 (타임프레임 필터)
```json
{
  "symbols": [
    {
      "symbol": "BTCUSDT",
      "candles": 125000,
      "timeframes": 7,
      "earliest": "2020-01-01T00:00:00",
      "latest": "2026-01-18T12:00:00"
    }
  ],
  "count": 150
}
```

### **GET /api/years?symbol=BTCUSDT**
년도별 통계 (심볼 필터)
```json
{
  "years": [
    {
      "year": 2023,
      "candles": 45000,
      "symbols": 1,
      "timeframes": 7
    }
  ]
}
```

### **GET /api/months?year=2023&symbol=BTCUSDT**
월별 통계
```json
{
  "year": 2023,
  "months": [
    {
      "month": 1,
      "candles": 3800,
      "symbols": 1,
      "timeframes": 7
    }
  ]
}
```

### **GET /api/days?year=2023&month=1&symbol=BTCUSDT**
일별 통계
```json
{
  "year": 2023,
  "month": 1,
  "days": [
    {
      "day": 1,
      "candles": 120,
      "symbols": 1,
      "timeframes": 7
    }
  ]
}
```

## ⚡ 성능 최적화

### **DB 연결 관리**

```python
# 모든 엔드포인트에서
conn = None
try:
    conn = get_db_connection()
    with conn.cursor() as cur:
        # 쿼리 실행
        pass
except Exception as e:
    # 에러 처리
    pass
finally:
    if conn:
        try:
            conn.close()  # 무조건 닫기
        except:
            pass
```

**효과:**
- 연결 누수 0%
- 장시간 실행 가능
- 안정적인 성능

### **쿼리 최적화**

```sql
-- 인덱스 활용
CREATE INDEX idx_candles_symbol ON candles(symbol);
CREATE INDEX idx_candles_tf ON candles(tf);
CREATE INDEX idx_candles_open_time ON candles(open_time);
CREATE INDEX idx_candles_symbol_tf_time ON candles(symbol, tf, open_time);
```
