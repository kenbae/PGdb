# 학습 기능 빠른 테스트 가이드

## 🚀 빠른 시작 (5분)

### 1단계: Matching 페이지 접속
```
https://localhost:8888/matching
```

### 2단계: 데이터 확인
1. **필터 설정**
   - Start Date: 데이터가 있는 날짜 선택 (예: 2026-01-20)
   - End Date: 데이터가 있는 날짜 선택 (예: 2026-01-25)
   - Symbol: All 또는 특정 심볼 선택

2. **"데이터셋 새로고침" 버튼 클릭**
   - 테이블에 데이터가 표시되는지 확인
   - 통계 카드 확인 (Total Signals, Matched 등)

### 3단계: 타이밍 모델 학습
1. **"타이밍 모델 학습" 버튼 클릭**
   - 학습 진행 중 표시 확인
   - 학습 결과 카드 확인:
     - 학습 샘플 수
     - 진입/청산 타이밍 통계

2. **결과 확인**
   - 심볼 옆에 `⏱️` 표시가 나타나는지 확인
   - 테이블의 심볼 클릭 시 학습 상세 정보 확인

### 4단계: 정책 모델 학습
1. **"정책 모델 학습" 버튼 클릭**
   - 학습 진행 중 표시 확인
   - 학습 결과 카드 확인

2. **"정책 요약" 버튼 클릭**
   - 최고 성과 시장 상태 목록 확인
   - 최고 성과 전략 목록 확인

3. **결과 확인**
   - 심볼 옆에 `🎯` 또는 `✓✓` 표시가 나타나는지 확인

### 5단계: Signals 페이지에서 예측 테스트
1. **Signals 페이지 접속**
   ```
   https://localhost:8888/signals
   ```

2. **신호 선택**
   - 테이블에서 신호 클릭 또는 상세 모달 열기

3. **타이밍 예측**
   - "⏱️ 타이밍 추천" 버튼 클릭
   - 진입/청산 타이밍 추천 확인

4. **정책 추천**
   - "🎯 정책 추천" 버튼 클릭
   - 진입 여부, 타이밍, 파라미터 추천 확인

## 🐛 문제 해결

### 학습 샘플 부족
**증상**: "학습 샘플 부족" 메시지 표시

**해결 방법**:
1. 더 긴 기간의 데이터 선택 (최소 1주일 이상 권장)
2. 매칭된 데이터가 충분한지 확인 (최소 10개 이상 권장)
3. Symbol 필터를 "All"로 설정하여 더 많은 데이터 사용

### 예측 결과가 "데이터 부족"
**증상**: 모든 예측이 기본값으로 표시됨

**해결 방법**:
1. 먼저 Matching 페이지에서 모델 학습 실행
2. 학습이 성공했는지 확인 (심볼 옆 표시 확인)
3. 해당 심볼에 대한 학습 데이터가 있는지 확인

### 심볼 표시가 안 나타남
**증상**: 학습 완료 후에도 심볼 옆에 표시가 없음

**해결 방법**:
1. 페이지 새로고침 (F5)
2. "데이터셋 새로고침" 버튼 클릭
3. 브라우저 콘솔에서 오류 확인 (F12)

## 💡 테스트 팁

1. **충분한 데이터 확보**: 최소 50개 이상의 매칭된 샘플 권장
2. **다양한 시장 상태**: 다양한 트렌드/변동성 조합이 있으면 더 정확한 학습
3. **정기적 재학습**: 새로운 데이터가 쌓이면 주기적으로 재학습
4. **콘솔 확인**: 브라우저 개발자 도구(F12)에서 로그 확인

## 📊 예상 결과

### 정상적인 경우
- **타이밍 모델 학습**: 진입 평균 10~30분, 청산 평균 2~6시간
- **정책 모델 학습**: 시장 상태별 패턴 5~20개, 전략별 패턴 3~10개
- **타이밍 예측**: 신뢰도 30~80%, 합리적인 시간 범위
- **정책 추천**: 승률 기반 진입 추천, 구체적인 타이밍 및 파라미터 제안

### 데이터가 부족한 경우
- 학습 샘플 부족 메시지
- 기본값으로 예측 (신뢰도 0%)
- "데이터 부족" 추천 등급

## 🎯 테스트 시나리오

### 시나리오 1: 전체 워크플로우 (15분)
1. Matching 페이지 접속
2. 데이터 로드 및 확인
3. 타이밍 모델 학습
4. 정책 모델 학습

1. Matching 페이지 접속

3. 학습 완료된 심볼만 표시되는지 확인
4. 심볼 클릭하여 학습 상세 정보 확인

### 시나리오 3: 실시간 예측 (5분)
1. Signals 페이지 접속
2. 최신 신호 선택
3. 타이밍 예측 및 정책 추천 확인
4. 추천 내용이 합리적인지 검토
