# 실시간 트레이딩 테스트 가이드

## 🚀 테스트 방법

### 1. 개발용 서버 실행

```bash
cd PGdb/tradeBot_dev/servers
python realtime_api.py
```

서버가 포트 8886에서 시작됩니다.

### 2. 브라우저에서 접속

```
http://localhost:8886
또는
https://localhost:8886 (HTTPS 모드인 경우)
```

### 3. 테스트 절차

1. **설정**
   - 심볼 선택 (예: BTCUSDT)
   - 전략 선택 (예: ema_cross)
   - 타임프레임 선택 (예: 5m)
   - 초기 자본 설정

2. **시작**
   - "실시간 모니터링 시작" 버튼 클릭
   - 모니터링 상태 로그 확인
   - 캔들 완성 대기

3. **신호 확인**
   - 전략이 신호를 생성하면 자동 진입
   - 포지션 정보 확인
   - 실시간 PnL 확인

4. **중지**
   - "중지" 버튼 클릭

## 🐛 문제 해결

### WebSocket 연결 실패
- 방화벽 확인
- Binance API 상태 확인

### 캔들 데이터 없음
- DB에 캔들 데이터가 있는지 확인
- `run_ingest.py`로 데이터 수집

### 전략 신호 없음
- 전략이 활성화되어 있는지 확인
- 충분한 캔들 데이터가 있는지 확인
